# Сервер для моделлеров

Пустая сборка без базы и ролевой логики. Залил DLC, зашёл, посмотрел.
Сборки нет: правишь файл, перезапускаешь сервер, заходишь.

## Запуск

Запустить `start.bat`, дождаться строки `The server is ready to accept connections`.
В лаунчере RAGE — Direct Connect на `127.0.0.1:22005`. С другого компа в сети —
вместо `127.0.0.1` локальный IP машины с сервером.

Окно консоли не закрывать, пока играешь. Закрыл окно — выключил сервер.

## Свой DLC

Папку с `dlc.rpf` кинуть в `client_packages\game_resources\dlcpacks\`, потом
в `client_packages\game_resources\x64\dlcpacks\dlclist.xml` дописать перед
`</Paths>` строку с именем папки:

```xml
<Item>dlcpacks:/my_car/</Item>
```

Вложенные папки работают: `dlcpacks\vehicles\my_car\` это
`<Item>dlcpacks:/vehicles/my_car/</Item>`.

Дальше перезапустить сервер, вычистить `RAGEMP\client_resources` и зайти.
Кэш чистить обязательно, иначе игра возьмёт старую версию пака.

Если пак что-то перекрывает, ставь его строку ниже той, что он должен перебить.
Паки грузятся сверху вниз.

## Клавиши

```
1                меню
H                ноуклип
J                телепорт на метку с карты
WASD             полёт
Space / Ctrl     вверх / вниз
Shift / Alt      быстрее / медленнее
колесо           скорость полёта
```

Хоткеи меняются в начале `client_packages\index.js`, объект `KEYS`.


Погоды: EXTRASUNNY, CLEAR, CLOUDS, SMOG, FOGGY, OVERCAST, OVERCAST_DARK,
CLEARING, RAIN, THUNDER, NEUTRAL, SNOW, SNOWLIGHT, BLIZZARD, XMAS, HALLOWEEN.

Вместо имени модели везде можно вписать хеш числом.

## Меню

**Транспорт** — спавн по имени модели, покраска в два цвета, починка, удаление.
Последние модели остаются кружками, клик по кружку спавнит сразу.

**Мир** — время слайдером и пресетами, погода, телепорт по координатам,
кнопка сноса и возврата ванильного Лос-Сантоса.

**Игрок** — модель педа, компоненты одежды и пропы, скорость полёта,
скрытие игрового интерфейса под скрины.

**Оружие** — выдача по имени с патронами, готовые кружки, набор из шести
стволов, добивка патронов в руки.

Внизу меню текущие координаты и кнопка копирования.

Компоненты одежды: 0 голова, 1 маска, 2 волосы, 3 торс, 4 ноги, 5 сумка,
6 обувь, 7 аксессуар, 8 майка, 9 броня, 10 наклейки, 11 верх.
Пропы: 0 шляпа, 1 очки, 2 серьги, 6 часы, 7 браслет. Вариант -1 снимает.

## Ванильная карта

Лос-Сантос сносится сам через пару секунд после захода, чтобы своя карта
не резалась с игровой. Вернуть можно кнопкой во вкладке «Мир». Чтобы не
сносился вообще, поставь `HIDE_VANILLA_MAP = false` в `client_packages\index.js`.

## Если не работает

**Меню пишет «модель не загружена».** Игра не видит модель. Проверь имя модели
из `vehicles.meta` (не имя папки и не имя файла), строку в `dlclist.xml`,
что файл называется ровно `dlc.rpf`, и что кэш почищен.

**Изменений не видно.** Почти всегда кэш: удали всё из `RAGEMP\client_resources`,
перезапусти сервер.

**Машина розовая или без колёс.** Модель загрузилась, дело в паке: `.ytd`,
`vehicles.meta`, имена. Сервер тут ни при чём.

**Пропал город.** Так и надо, ванилка снесена. Вернуть во вкладке «Мир».

**Провалился под карту.** Нажать H, взлететь, выключить H.

**В ноуклипе не летишь.** Открыт чат, там движение отключено специально.

**Сервер не стартует.** Смотри консоль. `Address already in use` значит порт
22005 занят, поменяй `port` в `conf.json`.

## Вместе на одном сервере

Мешаете друг другу спавнами — уйди в своё измерение через `/dim 5`, вернуться
`/dim 0`. Время и погода общие для всех.
