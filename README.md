# ragemp-modellers-server

Пустой сервер RAGE:MP для моделлеров и маперов GTA 5. Залил свой DLC, зашёл,
посмотрел в игре. Без базы данных, авторизации и ролевой логики.

Сборки нет: всё на обычном JS и HTML/CSS. Правишь файл, перезапускаешь сервер,
заходишь.

## Что умеет

- меню на клавишу `1`, выезжает справа
- спавн машин по имени модели или хешу, покраска, починка, удаление
- ноуклип на `H` с регулируемой скоростью
- телепорт на метку с карты на `J` и по координатам через `/tpxyz`
- время и погода
- смена модели педа, компоненты одежды и пропы
- выдача оружия с патронами
- снос ванильного Лос-Сантоса, чтобы своя карта не резалась с игровой
- скрытие игрового интерфейса под скриншоты

Меню прямо говорит «модель не загружена», если пак не подхватился, так что
сразу видно, где искать проблему: в `dlclist.xml` или в самом `dlc.rpf`.

## Установка

1. Скачать серверные файлы RAGE:MP с [rage.mp](https://rage.mp) и положить в
   папку `ragemp-server.exe`, `BugTrap-x64.dll` и папку `bin`.
2. Скачать этот репозиторий туда же.
3. Запустить `start.bat`.
4. В лаунчере RAGE — Direct Connect на `127.0.0.1:22005`.

## Свой DLC

Папку с `dlc.rpf` положить в `client_packages/game_resources/dlcpacks/`, затем
в `client_packages/game_resources/x64/dlcpacks/dlclist.xml` дописать перед
`</Paths>`:

```xml
<Item>dlcpacks:/my_car/</Item>
```

Вложенные папки работают: `dlcpacks/vehicles/my_car/` это
`<Item>dlcpacks:/vehicles/my_car/</Item>`.

Дальше перезапустить сервер, вычистить `RAGEMP\client_resources` и зайти.
Кэш чистить обязательно, иначе игра возьмёт старую версию пака.

## Клавиши

```
1                меню
H                ноуклип
J                телепорт на метку
WASD             полёт
Space / Ctrl     вверх / вниз
Shift / Alt      быстрее / медленнее
колесо           скорость полёта
```

Меняются в объекте `KEYS` в начале `client_packages/index.js`.

## Команды

```
/veh модель      спавн машины           /time час мин    время
/vehin модель    спавн и сесть          /weather имя     погода
/dv /dvall       удалить последнюю/все  /tpxyz x y z     телепорт
/fix             починить               /tp id           к игроку
/skin модель     сменить педа           /dim номер       измерение
/weapon имя n    оружие с патронами     /pos             координаты
/guns /ammo /delweapons                 /help            подсказка
```

## Структура

```
conf.json                     настройки, порт
packages/modellers/index.js   сервер
client_packages/index.js      ноуклип, телепорты, хоткеи, снос IPL
client_packages/ipl_list.js   список IPL Лос-Сантоса
client_packages/cef/          меню
```

Точка спавна — константа `SPAWN` в `packages/modellers/index.js`.
Автоснос ванильной карты выключается через `HIDE_VANILLA_MAP` в клиентском файле.

Подробнее для моделлеров — в [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).
